# House Construction Masterplan

This repository is a starter project to plan, track, and control a house construction program from idea to handover.

## Goal
Build a **single source of truth** for your house project so you can:
- define scope and budget clearly,
- sequence work by phase,
- track risks, permits, and decisions,
- monitor weekly progress,
- avoid expensive rework.

## Project Structure

```text
.
├── readme.md
├── masterplan
│   ├── 01-project-charter.md
│   ├── 02-work-breakdown-structure.md
│   ├── 03-schedule-template.csv
│   ├── 04-budget-template.csv
│   ├── 05-risk-register.csv
│   └── 06-weekly-status-template.md
```

## How To Use This
1. Start with `masterplan/01-project-charter.md` and fill in the vision, scope, and constraints.
2. Break construction into work packages in `masterplan/02-work-breakdown-structure.md`.
3. Build an initial timeline in `masterplan/03-schedule-template.csv`.
4. Define cost categories in `masterplan/04-budget-template.csv`.
5. Track threats and mitigations in `masterplan/05-risk-register.csv`.
6. Run weekly reviews using `masterplan/06-weekly-status-template.md`.

## Recommended Workflow
- Update schedule and budget every week.
- Record major decisions with date and owner.
- Promote unresolved blockers into the risk register.
- Keep all assumptions explicit (especially utility connections, permit lead times, and material availability).

## Milestones (example)
- Land/legal clearance complete
- Concept + schematic design approved
- Permit package submitted / approved
- Foundation complete
- Structure and roof complete
- MEP rough-ins complete
- Finishes complete
- Inspection and handover complete
